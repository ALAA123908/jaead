# jawad market

تطبيق توصيل لسوبر ماركت باسم "jawad market" مع لوحة تحكم للإدارة.

## المميزات
- تصفح المنتجات وإضافتها للسلة
- إتمام الطلب وإدخال بيانات العميل
- لوحة تحكم للإدارة لإدارة المنتجات والطلبات

## بدء التشغيل

1. تثبيت الحزم:
   ```bash
   npm install
   ```
2. تشغيل التطبيق:
   ```bash
   npm start
   ```

## التقنية المستخدمة
- React
- MUI (تصميم عصري)
